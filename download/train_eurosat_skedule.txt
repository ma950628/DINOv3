# 使用 HuggingFace EuroSAT 数据集在 Docker 中跑通 DINOv3 训练

根据你提供的 README，EuroSAT 数据集可以通过 HuggingFace `datasets` 库直接加载。下面是在 Docker 容器中完整跑通 DINOv3 训练的指南。

## 一、Docker 环境准备

### 1.1 拉取基础镜像

```bash
docker pull pytorch/pytorch:2.1.0-cuda12.1-cudnn8-runtime
```

### 1.2 创建并启动容器

```bash
docker run --gpus all -it \
  --name dinov3_eurosat \
  --shm-size=16g \
  -v /path/to/dinov3:/workspace/dinov3 \
  pytorch/pytorch:2.1.0-cuda12.1-cudnn8-runtime \
  bash
```

参数说明：
- `--gpus all`：启用所有 GPU
- `--shm-size=16g`：共享内存大小，防止数据加载时 OOM
- `-v`：挂载 DINOv3 代码目录

## 三、准备 EuroSAT 数据

### 3.1 创建数据加载脚本

由于 DINOv3 需要特定的目录结构，我们需要将 HuggingFace 的 EuroSAT 数据转换为 DINOv3 格式。

创建脚本 `/workspace/prepare_eurosat.py`：

```python
# prepare_eurosat.py
import os
from datasets import load_dataset
from PIL import Image
from pathlib import Path
import random
from tqdm import tqdm

def prepare_eurosat_for_dinov3(output_dir: str = "./data/eurosat_dinov3"):
    """
    从 HuggingFace 加载 EuroSAT 数据集并转换为 DINOv3 格式
    DINOv3 需要: root/train/class_name/images.jpg 和 root/val/class_name/images.jpg
    """
    print("正在从 HuggingFace 加载 EuroSAT 数据集...")
    dataset = load_dataset("tranganke/eurosat")
    
    # 类别名称映射
    class_names = [
        "annual_crop_land",
        "forest", 
        "brushland_or_shrubland",
        "highway_or_road",
        "industrial_or_commercial",
        "pasture_land",
        "permanent_crop_land",
        "residential",
        "river",
        "lake_or_sea"
    ]
    
    # 创建输出目录
    output_path = Path(output_dir)
    for split in ['train', 'val']:
        for class_name in class_names:
            (output_path / split / class_name).mkdir(parents=True, exist_ok=True)
    
    # 处理训练集 (21600张)
    print("处理训练集...")
    for idx, sample in enumerate(tqdm(dataset['train'])):
        image = sample['image']
        label = sample['label']
        class_name = class_names[label]
        
        # 保存图像
        image_path = output_path / 'train' / class_name / f"img_{idx:06d}.JPEG"
        if image.mode == 'RGBA':
            image = image.convert('RGB')
        image.save(image_path)
    
    # 处理测试集并分割为 val (使用测试集作为验证集)
    print("处理验证集 (从测试集分割)...")
    test_data = dataset['test']
    # 随机打乱并分割
    indices = list(range(len(test_data)))
    random.seed(42)
    random.shuffle(indices)
    
    val_size = len(test_data)  # 使用全部测试集作为验证集
    for idx, data_idx in enumerate(tqdm(indices[:val_size])):
        sample = test_data[data_idx]
        image = sample['image']
        label = sample['label']
        class_name = class_names[label]
        
        image_path = output_path / 'val' / class_name / f"img_{idx:06d}.JPEG"
        if image.mode == 'RGBA':
            image = image.convert('RGB')
        image.save(image_path)
    
    # 生成 labels.txt 文件
    with open(output_path / "labels.txt", "w") as f:
        for class_name in class_names:
            f.write(f"{class_name}\n")
    
    print(f"数据准备完成！输出目录: {output_path}")
    print(f"训练集类别: {len(class_names)}")
    
    # 统计信息
    train_count = sum(1 for _ in (output_path / 'train').rglob('*.JPEG'))
    val_count = sum(1 for _ in (output_path / 'val').rglob('*.JPEG'))
    print(f"训练集图片数: {train_count}")
    print(f"验证集图片数: {val_count}")
    
    return output_path

if __name__ == "__main__":
    prepare_eurosat_for_dinov3("/workspace/data/eurosat_dinov3")
```

### 3.2 运行数据准备脚本

```bash
cd /workspace
python prepare_eurosat.py
```

### 3.3 生成 DINOv3 元数据

```bash
cd /workspace/dinov3
python -c "
from dinov3.data.datasets import ImageNet
from pathlib import Path

data_path = Path('/workspace/data/eurosat_dinov3')
for split in [ImageNet.Split.TRAIN, ImageNet.Split.VAL]:
    print(f'生成 {split} 元数据...')
    dataset = ImageNet(split=split, root=str(data_path), extra=str(data_path))
    dataset.dump_extra()
    print(f'{split} 完成')
"
```

## 四、创建 DINOv3 训练配置

创建配置文件 `/workspace/dinov3/eurosat_config.yaml`：

```yaml
# EuroSAT 训练配置
MODEL:
  META_ARCHITECTURE: SSLMetaArch

# 使用 ViT-Small 进行快速训练
student:
  arch: vit_small
  patch_size: 16
  drop_path_rate: 0.1
  layerscale: 1.0e-05
  qkv_bias: true
  proj_bias: true
  ffn_bias: true
  norm_layer: layernorm

# 训练超参数（针对小数据集优化）
optim:
  epochs: 20
  batch_size_per_gpu: 64
  lr: 0.0005
  warmup_epochs: 2
  layerwise_decay: 0.9
  clip_grad: 3.0
  weight_decay: 0.04
  weight_decay_end: 0.4

# DINO 损失配置
dino:
  loss_weight: 1.0
  koleo_loss_weight: 0.1
  head_n_prototypes: 4096
  head_bottleneck_dim: 256
  head_hidden_dim: 2048
  head_nlayers: 3

# iBOT 损失（可禁用加速训练）
ibot:
  loss_weight: 0.0
  separate_head: true
  mask_ratio_min_max: [0.1, 0.5]
  mask_sample_probability: 0.5

# Gram 损失（禁用）
gram:
  use_loss: false

# 数据增强
crops:
  global_crops_scale: [0.32, 1.0]
  local_crops_number: 8
  local_crops_scale: [0.05, 0.32]
  global_crops_size: 224
  local_crops_size: 96
  # EuroSAT 使用标准 ImageNet 归一化（RGB 图像）
  rgb_mean: [0.485, 0.456, 0.406]
  rgb_std: [0.229, 0.224, 0.225]
  horizontal_flips: true

# 训练配置
train:
  dataset_path: "ImageNet:split=TRAIN:root=/workspace/data/eurosat_dinov3:extra=/workspace/data/eurosat_dinov3"
  output_dir: "/workspace/eurosat_output"
  saveckp_freq: 100
  num_workers: 4
  OFFICIAL_EPOCH_LENGTH: 338  # EuroSAT 训练集 21600 / 64 ≈ 338
  seed: 42
  cache_dataset: true
  centering: sinkhorn_knopp

# 评估配置
evaluation:
  eval_period_iterations: 500

# 精度配置
compute_precision:
  param_dtype: bf16
  reduce_dtype: fp32
  sharding_strategy: SHARD_GRAD_OP

teacher:
  momentum_teacher: 0.996
  final_momentum_teacher: 1.0
  warmup_teacher_temp: 0.04
  teacher_temp: 0.07
  warmup_teacher_temp_epochs: 10
```

## 八、常见问题解决

| 问题 | 解决方案 |
|------|----------|
| `datasets` 下载慢 | 设置 HF 镜像：`export HF_ENDPOINT=https://hf-mirror.com` |
| 显存不足 | 减小 `batch_size_per_gpu` 到 32 或 16 |
| 数据集加载慢 | 配置中设置 `cache_dataset: true` |
| 容器内网络问题 | 使用 `--network host` 启动容器 |

## 九、一键运行脚本

创建 `run_dinov3_eurosat.sh`：

```bash
#!/bin/bash

# 构建镜像并运行
docker run --gpus all -it \
  --name dinov3_eurosat \
  --shm-size=16g \
  --network host \
  -v $(pwd)/dinov3:/workspace/dinov3 \
  -v $(pwd)/data:/workspace/data \
  -v $(pwd)/output:/workspace/output \
  pytorch/pytorch:2.1.0-cuda12.1-cudnn8-runtime \
  bash -c "
    # 安装依赖
    pip install omegaconf submitit termcolor torchmetrics ftfy regex datasets
    
    # 安装 DINOv3
    cd /workspace/dinov3 && pip install -e .
    
    # 准备数据
    cd /workspace && python prepare_eurosat.py
    
    # 生成元数据
    cd /workspace/dinov3
    python -c \"
from dinov3.data.datasets import ImageNet
for split in [ImageNet.Split.TRAIN, ImageNet.Split.VAL]:
    ImageNet(split=split, root='/workspace/data/eurosat_dinov3', extra='/workspace/data/eurosat_dinov3').dump_extra()
\"
    
    # 启动训练
    PYTHONPATH=. torchrun --nproc_per_node=4 dinov3/train/train.py \
        --config-file eurosat_config.yaml \
        --output-dir /workspace/output/eurosat_run
  "
```

运行：

```bash
chmod +x run_dinov3_eurosat.sh
./run_dinov3_eurosat.sh
```
